QUESTIONS

New player FAQ

What versions can I join on?+

The main server version is 26.2, and any version 1.17 or above can join. The server updates toward the newest Minecraft version over time.

Can I grief things?+

Yes. Raiding, griefing, and base hunting are part of the server. Build with that risk in mind.

How do I report a player or a bug?+

Join the Discord and open a ticket, or use /report in game.
