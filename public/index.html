      QUESTIONS

      FAQ

      What versions can I join on?+

      The main server version is 26.2, and any version 1.17 or above can join. The server updates toward the newest Minecraft version over time.

      Is the server pay-to-win?+

      No. The store has two non-P2W ranks: a $5 permanent rank and a $10 monthly rank. Ranked players can also spend in-game gold or money to start events.

      Can I grief things?+

      Yes. Raiding, griefing, and base hunting are part of the server. Build with that risk in mind.

      Are there any events?+

      Yes. Death Duels are live now and the first competitions run through October and November. Server events (about every hour, with their own inventories) and KOTH (about every eight hours) return later in Chapter 2.

      Where are the rules?+

      You can read the full rule list on the Rules page.

      How do I report a player or a bug?+

      Join the Discord and open a ticket, or use /report in game.

      Where can I get more detailed server info?+

      For deeper info on mechanics, features, and guides, check the Enthusia wiki.
