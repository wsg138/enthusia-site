# Mobile wiki UX pass

Goals for the public Vector 2022 mobile experience:

- reduce vertical scrolling by using denser 3-column home cards and 2-column topic/fact grids on normal phones;
- reduce padding, margins and summary height on mobile while keeping tap targets usable;
- restore the Enthusia logo and colored `Enthusia SMP` brand in the header;
- provide an obvious mobile Menu/Home/Theme control bar;
- expose the existing native `MediaWiki:Sidebar` content in a mobile drawer rather than duplicating a separate navigation source;
- use Vector's native light/night inputs when available, with a local fallback only when the native control is unavailable;
- preserve desktop behavior and all existing wiki history/content.
